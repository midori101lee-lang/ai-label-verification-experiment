# 材料纯净度审计（Material Audit）

> 针对「AI标识 × 内容证据一致性」3×2 实验刺激材料的可理解性与纯净度审查。
> 本轮重点：让**无统计学/医学背景的普通人**也能仅凭正文自然语言读懂材料，同时不泄露实验目的。

## 一、实验条件（6 个，正交）

| AI_label | 证据一致 (0) | 证据冲突 (1) |
| --- | --- | --- |
| 0 无标识 | 0/0 | 0/1 |
| 1 AI辅助 | 1/0 | 1/1 |
| 2 AI生成 | 2/0 | 2/1 |

- **AI_label** 操纵「谁/什么生产了内容」（来源·生产过程层），以署名行下方灰色 chip「AI 辅助 ⓘ」/「AI 生成 ⓘ」呈现，三条件视觉规格完全一致，只改变文字。
- **evidence_consistency** 操纵「内容内部几项结果是否互相支持」（内容·证据层），通过**结果方向**制造，不更换或贬低来源。
- 两条来源标签在 6 个条件中**逐字相同**，因此两个自变量在构念上正交。

## 二、材料可理解性优化（已落地）

1. **正文不出现 p 值**：统计数字与检验结果统一收入正文下方默认收起的「查看详细数据」折叠区（脚本实测：p 值出现 0 次）。
2. **不出现专业指标名**：正文只写「另一项与眼睛状态有关的指标」，指标名仅出现在折叠区（正文中出现 0 次）。
3. **证据二两版标题完全相同**：均为「另一项观察指标」；差异仅压缩到正文最后一句。
4. **一致条件**：两项结果均呈现较明显变化，方向一致。
5. **冲突条件**：第一项明显改善，第二项只有较小变化（**不是「完全无效」**，避免滑向真假判断）。
6. **证据三不再承担专家裁判**：改为研究背景信息（参与者来源、测试周期、后续计划），不含任何判断；正文专家判断词 0 次。
7. **核验区措辞中性化**：标题改为「如果你希望进一步了解这项研究，可以查看以下相关材料」；「暂不查看其他材料」置于首位，五个选项视觉权重相等。

## 三、纯净度审计（14 项要点）

| # | 审计项 | 判定 |
| --- | --- | --- |
| 1 | AI标识是否改变来源信息之外的内容 | 干净（共用同一模板与正文，标签独立节点） |
| 2 | 一致/冲突是否改变证据数量 | 干净（均 3 组证据） |
| 3 | 一致/冲突是否改变来源可信度 | 干净（三来源逐字相同，无第三方权威） |
| 4 | 是否改变新闻长度 | 已配平（差异仅证据二方向句 + 折叠区一个数值） |
| 5 | 是否改变语言强度 | 干净（无「不一致/冲突/矛盾」等判断词） |
| 6 | 冲突是否过于明显 | 需预测试（目标 Q2/Q3 正确率 80%–95%） |
| 7 | 参与者是否猜到研究目的 | 低—中（已消除三个主要线索） |
| 8 | 是否需要专业知识 | 不需要（只需理解「一项明显改善、一项没跟上」） |
| 9 | 验证行为是否真代表验证 | 部分代表（4 个入口含实质信息） |
| 10 | 两自变量是否可理论区分 | 可以（分属来源层与内容层，正交） |
| 11 | 专家/权威判断频率 | 0 次 |
| 12 | 正文统计术语与 p 值 | 0 次 |
| 13 | 三张信息卡视觉突出度 | 等权 |
| 14 | 开发者开关是否污染正式材料 | 默认关闭（速览行/高亮仅影响研究者视图） |

**最大遗留问题**：信息完整度在冲突版客观上更高（操纵固有属性，无法靠配平消除）。处置：在论文「研究局限」中写明，或加「信息量控制组」。

## 四、预测试模式映射（参与者视图）

参与者随机分配条件（隐藏），作答**不显示对错、不显示条件**，数据本机记录：

| 预测试题 | 记录字段 | 对应诊断 |
| --- | --- | --- |
| Q1 护眼模式学生是否更舒服 | `q1` | 材料理解 |
| Q2 不同结果变化是否一致（1–7） | `q2_consistency` | 一致性操纵检验 |
| Q3 能否查资料得明确判断（1–7） | `q3_resolvability` | 可化解性（辅助诊断，非核心中介） |
| Q4 是否存在明显错误信息 | `q4_false_info` | 假信息混淆诊断 |
| 开放题 哪里难懂 | `open_feedback` | 材料可理解性 |

研究者可在「⑦ 预测试数据」标签按 `AI_label` / `evidence_consistency` 汇总（字段含 condition，但参与者页面不可见）。

## 五、不可作为核心理论模型的变量

- 可化解性（Q3 / `resolvability_check`）：仅回答「差异能否通过进一步查阅得到更明确判断」，用作辅助诊断。
- 是否存在明显错误信息（Q4 / `false_info_check`）：仅监控冲突是否被读成「假新闻」。
- 二者均**不加入**当前核心理论模型（AI标识 → 感知可信度 → 信息验证行为）。
