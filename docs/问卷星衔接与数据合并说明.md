# 问卷星衔接与数据合并说明

> 目的：把"网页记录的实验行为数据"与"问卷星记录的量表数据"通过同一个匿名编号关联起来。
> 原则：被试操作简单、研究者回收方便、不无意收集身份信息。

## 1. 匿名编号 `participant_id` 的生成与流转

- 网页在参与者**知情同意之后、条件分配之时**生成 `participant_id`（格式 `EXP-XXXXXXXX`，随机串）。
- 同一编号与本机随机分配的条件（`AI_label` / `evidence_consistency`）绑定，写入浏览器 `localStorage`（键 `exp_session`），**刷新/后退不会重分配**。
- 完成实验后，编号显示在"完成页"并支持一键复制；同时尝试通过 URL 参数带入问卷星。

## 2. 网页 → 问卷星的两种衔接方式（按问卷星实际能力二选一）

### 方式 A：URL 参数自动带入（优先，若问卷星支持）
- 在 `index.html` 顶部 `EXP_CONFIG.SURVEY_URL` 填写问卷星链接，例如：
  `https://www.wjx.cn/vm/XXXXXXXX.aspx`
- 系统自动拼接：`?pid=EXP-XXXXXXXX`（参数名由 `SURVEY_ID_PARAM` 控制，默认 `pid`）。
- 前提：**问卷星题目里需有一个"研究编号"填空题，并开启"参数带入/默认值"功能**（问卷星专业版支持 `?name=默认值` 形式；具体参数名以问卷星后台为准，请按实际改 `SURVEY_ID_PARAM`）。
- 若问卷星不支持参数带入，请改用方式 B，不要假设已自动填入。

### 方式 B：手动回填（最稳妥的备用方案）
- 完成页明确提示参与者"复制编号并填入问卷星的'研究编号'一栏"。
- 即使方式 A 配置失败，方式 B 仍可保证编号被记录。

> ⚠️ 不对问卷星尚未具备的"嵌入、传参、自动提交"能力做任何假设；若 `SURVEY_URL` 留空，完成页只显示编号与手动回填说明，不会凭空跳转。

## 3. 完成页引导
- 完成页包含：研究编号（大字 + 复制按钮）、问卷星入口按钮、实验记录下载（XLSX 主下载 + JSON 备用）、复制编号按钮。
- 参与者下载 `experiment_<participant_id>.xlsx`（含 `participant_summary` / `event_log` / `raw_json` 三表），将其**上传至问卷星的必答文件上传题**，研究者即可从问卷星侧拿到每位参与者的完整实验记录（无需再从网页后台逐一导出）。
- 若未配置 `SURVEY_URL`，入口按钮显示为"正式问卷链接尚未配置"且不可点击，并提示手动回填。

## 4. 数据合并步骤（研究者端，离线）
1. 从问卷星回收：问卷星后台导出答卷（**务必包含"研究编号"填空题 + 必答文件上传题**）；上传的 `experiment_<pid>.xlsx` 随答卷一并下载，解压/读取后即为该参与者的完整实验记录。
2. 从网页回收（备用，仅本机）：研究者模式「⑦ 实验参与者数据」为**只读本地视图**，仅显示当前浏览器已存的记录，**无下载按钮**；跨设备记录须靠问卷星上传的 XLSX 汇总。
3. 以 `participant_id`（网页）与"研究编号"（问卷星）为键，做 **left join**：
   - 左表 = 实验记录（行为数据 + 条件）；右表 = 问卷星答卷（量表数据）。
   - 输出合并宽表，供后续 3×2 方差分析、logistic 回归、有调节的中介（PROCESS Model 7）等使用。
4. 工具建议：Python（`pandas.merge`）、R（`merge`/`left_join`）、或 Excel 的 `XLOOKUP`/`VLOOKUP`。

## 5. 异常参与者的识别与处理

| 情况 | 识别方法 | 处理建议 |
|---|---|---|
| 只有实验记录、没有问卷记录 | 实验 `participant_id` 在问卷星导出的"研究编号"中找不到 | 行为数据可用，但缺量表 → 标记为"缺失问卷"，分析时视模型决定是否保留其主 DV |
| 只有问卷记录、没有实验记录 | 问卷"研究编号"在实验记录中找不到（如编号填错/未填） | 量表可用但缺条件与行为 → 无法进入 3×2 分析，建议剔除或单独标注 |
| 重复提交 | 同一 `participant_id` 出现多次（实验端），或问卷星同一"研究编号"多次 | 实验端通过 `exp_session` 的 `completed` 标记已防同浏览器重复；跨设备/跨浏览器重复须靠问卷星"研究编号+IP/填答时间"去重 |
| 编号填错/未填 | 问卷"研究编号"为空或格式不符 `EXP-XXXXXXXX` | 清洗时标记为"编号缺失"，不强行匹配 |

## 6. 仍需要研究者确认/配置的事项
- 问卷星链接、是否开通参数带入、参数名。
- 问卷星中"研究编号"题的类型与必填设置。
- 量表题目与顺序（感知可信度、VOI-7、一致性感知、AI 态度、卷入度、人口学、注意力测试）最终定稿后，由问卷星统一采集；**实验网页（exp-v2 起）不再采集任何问卷题项（含理解题与 AI 标识操纵检验）**，仅负责随机分组、新闻阅读、核验行为记录、编号生成与本地导出。分工为：网页=实验过程+行为+编号；问卷星=全部量表与操纵检验。
- 跨参与者的**均衡随机**是否需要服务端（当前网页随机为纯前端，不保证跨样本各 cell 人数相等；如需严格均衡，可在部署 `docs/服务端部署与后台说明.md` 中的后端时加随机分配/计数端）。
